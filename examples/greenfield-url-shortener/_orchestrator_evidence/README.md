# Provenance of this example

This URL-shortener service was **generated by the agentic SDLC orchestrator** in this repository
(live greenfield run `run_c856232d1346`, Claude Opus 5.5 agents). No human wrote its code.

| File | What it is |
|---|---|
| `ENGINEERING_SUMMARY.md` | Per-run summary generated by the orchestrator: requirements, plan, ADRs, validation gates, approvals, metrics, artifact lineage |
| `RELEASE_NOTES.md` | Release notes produced by the release gate |
| `manifest.json` | Release manifest: commit, bundle sha256, every approval (who/what), readiness checklist, SBOM |
| `GIT_HISTORY.txt` | The run's git history: one commit + merge per work package / repair attempt |

Reproduce: `sdlc run scenarios/greenfield.yaml` (needs an Anthropic API key). Output differs in
detail between runs (LLM non-determinism) but must pass the same gates.
